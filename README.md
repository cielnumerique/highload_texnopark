# highload_texnopark
## 1. Тема и целевая аудитория

### Тип сервиса

Высоконагруженный видеостриминговый сервис (на примере Netflix).

### Целевая аудитория

По данным акционерного отчёта Netflix за Q4 2024 (последний квартал, за который компания публиковала точное число подписчиков), у сервиса было около 301,6 млн платных подписок по всему миру [1].

По оценкам сторонних агрегаторов (Business of Apps, Backlinko), месячная аудитория Netflix (MAU) оценивается в диапазоне 315 млн пользователей [2][3]
Netflix отчитывается по четырём регионам. Ориентировочное распределение платных подписок по регионам[1]:

| Регион | Подписчики, млн | Доля |
|---|---|---|
| UCAN (США и Канада) | ~89,6 | ~30% |
| EMEA (Европа, Ближний Восток, Африка) | ~99,5 | ~33% |
| LATAM (Латинская Америка) | ~49,2 | ~16% |
| APAC (Азиатско-Тихоокеанский регион) | ~63,3 | ~21% |[1].

Ядро аудитории — 18–49 лет (более 70% зрителей), но сервисом пользуются все возрастные группы, включая детские профили[3]
## Функционал MVP

- Регистрация и авторизация пользователей
- Просмотр главной страницы с персонализированной лентой рекомендаций
- Поиск и просмотр карточки тайтла (фильм/сериал) с описанием, рейтингом, эпизодами
- Адаптивный видеостриминг с переключением качества (ABR) в зависимости от скорости соединения
- Сохранение прогресса просмотра и синхронизация между устройствами («продолжить просмотр»)
- Список «Мой список» / избранное
- Оценка тайтлов для персонализации рекомендаций

## Ключевые продуктовые решения

- Главная страница и рекомендации формируются персонально для каждого профиля на основе истории просмотров и оценок.
- Видео раздаётся через CDN с адаптивным битрейтом (ABR): клиент переключается между заранее подготовленными по HLS/DASH качествами в зависимости от пропускной способности сети.
- Прогресс просмотра сохраняется на сервере и синхронизируется между устройствами в реальном времени, чтобы пользователь мог продолжить просмотр с любого устройства.
- Оценка тайтла доступна только после окончания просмотра, чтобы рекомендации строились на реальном опыте пользователя, а не на случайных оценках.

## 2.1 Продуктовые метрики

**MAU и DAU**

| Метрика | Значение | Источник / метод расчёта |
|---|---|---|
| MAU (месячная аудитория) | ≈ 315 млн | Оценка сторонних агрегаторов (Business of Apps, Backlinko), раздел 1 [2][3] |
| DAU (дневная аудитория) | ≈ 189 млн | Расчёт: DAU/MAU ≈ 0,6. Netflix не публикует DAU напрямую; коэффициент принят на основе категории «ежедневно используемый контентный сервис» (ближайший ориентир — 40–60%+ для приложений с алгоритмической лентой [4]) |
| Среднее время просмотра на одного DAU-пользователя в активный день | ≈4 ч | 2,4 ч (средняя по всем аккаунтам и дням) ÷ 0,6 (DAU/MAU) [5] |

|---|---|
| Аутентификация (логин / refresh токена) | 2,0 |
| Открытие главной / ленты рекомендаций | 3,0 |
| Поисковый запрос | 1,5 |
| Открытие карточки тайтла | 5,0 |
| Запуск воспроизведения (фильм/эпизод) | 3,0 |
| Добавление/удаление из «Моего списка» | 0,4 |
| Оценка тайтла | 0,3 |

### 2.2 Технические метрики
**Средний размер хранилища пользователя**

Видеоконтент в Netflix не хранится «на пользователя» - каталог общий и раздаётся всем через CDN. Пользовательские данные ограничены профилем, историей и настройками; их объём в пересчёте на пользователя пренебрежимо мал (десятки-сотни КБ) и не выделяется отдельно в гигабайтах, только в штуках:

| Тип данных | Среднее кол-во записей на пользователя |
|---|---|
| Профиль/аккаунт | 1 |
| «Мой список» (избранное) | ≈ 25 тайтлов |
| История просмотра / прогресс | ≈ 300 записей (эпизод/фильм + позиция) |
| Оценки тайтлов | ≈ 60 записей |
| **Итого записей** | **≈ 386** (≈ 115 КБ при ~300 байт/запись) |


**Размер хранения по типам данных**

Допущения для каталога: суммарный уникальный каталог (с учётом различий между регионами: 7 600–8 900 тайтлов [6]) — ≈ 10 000 тайтлов; 45% фильмы / 55% сериалы; в среднем 25 эпизодов на сериал; средняя длительность фильма 110 мин, эпизода 48 мин -> 142 000 видеоединиц, ≈ 118 250 часов уникального контента.

| Уровень качества | Объём данных за час 
| --- | ---:
| Low, до 480p | 0,3 ГБ/ч 
| SD, 480p | 1 ГБ/ч 
| HD, 720–1080p | 3 ГБ/ч|
  4K | 7 ГБ/ч|
**Все версии одного часа контента** | **≈11,3 ГБ/ч** | из итсочника [8]

| Тип данных | Кол-во единиц | Объём, ТБ | Допущения |
|---|---|---|---|
| Видео - раздача | ≈ 142 000 видеоединиц | ≈ 1 336 ТБ ТБ | ≈11,3 ГБ/час контента по всей лестнице качеств, на основе битрейтов по уровням [8] |
| Видео - архивные мастер-копии (mezzanine) | ≈ 142 000 видеоединиц | ≈ 9 460 ТБ (≈9,5 ПБ) | ≈80 ГБ/час — типовой mezzanine-битрейт для архивного хранения |
| Метаданные и превью (описания, постеры, обложки) | ≈ 10 000 тайтлов | ≈ 1 ТБ | - |
| Пользовательские данные (профиль, история, список, оценки) | ≈ 315 млн профилей | ≈ 36,5 ТБ | - |
| **Итого** | | **≈ 11 700 ТБ (≈11,7 ПБ)** | 

Для сравнения: по собственному заявлению Netflix 2016 года, полный каталог «во всех форматах» оценивался в ~90 ПБ [9] - расхождение с расчётом объясняется ростом эффективности кодирования[10] с 2016 года и тем, что заявленная цифра включала избыточные копии на CDN.

### Динамика данных

Для прогноза роста пользовательской базы использована динамика платных подписок Netflix: 260,3 млн в Q4 2023 [11] и 301,6 млн в Q4 2024 [1].

Годовой темп роста = (301,6 − 260,3) / 260,3 × 100%= 15,9%

Новые пользователи за год:
315 млн × 15,9% ≈ 50,1 млн пользователей/год

Новые пользователи в сутки:
50,1 млн / 365 ≈ 137 тыс. пользователей/сутки

В 2025 году Netflix выпустил 597 новых тайтлов[6]; для расчёта значение округлено до 600 тайтлов в год.
Новые фильмы:
600 × 45% = 270 фильмов

Новые сериалы:
600 × 55% = 330 сериалов

Новые эпизоды:
330 × 25 = 8 250 эпизодов

Всего новых видеоединиц:
270 + 8 250 = 8 520 видеоединиц/год

Прирост пользовательских данных:
50,1 млн × 115,8 КБ ≈ 5,8 ТБ/год

Длительность новых фильмов:
270 × 110 мин / 60 = 495 ч

Длительность новых эпизодов:
8 250 × 48 мин / 60 = 6 600 ч

Итого нового контента:
495 + 6 600 = 7 095 ч/год

| Тип данных | Формула | Прирост за год |
| --- | --- | ---: |
| ABR-версии для раздачи | 7 095 ч/год × 18,8 ГБ/ч | ≈133 ТБ/год |
| Mezzanine/master-копии | 7 095 ч/год × 80 ГБ/ч | ≈568 ТБ/год |
| Метаданные и превью | 600 тайтлов/год × 100 МБ/тайтл | ≈0,06 ТБ/год |
| Данные новых пользователей | 50,1 млн/год × 115,8 КБ/пользователь | ≈5,8 ТБ/год |
| **Хранилище** |  | **≈707 ТБ/год** |



**RPS в разбивке по типам запросов**
Допущения: DAU ≈ 189 млн, среднее время просмотра на активного пользователя ≈ 4 ч/сутки -> 756 млн человеко-часов просмотра в сутки; коэффициент пик/среднее по нагрузке = 3[12][13].
Синхронизация: обновление каждые 30 секунд:
756 млн ч × 3 600 / 30 / 86 400 = 1,05 млн RPS.

Видеосегменты: сегмент длительностью 4 секунды:
756 млн ч × 3 600 / 4 / 86 400 = 7,875 млн RPS.

| Загрузка главной / ленты рекомендаций | ≈ 6 600 | ≈ 19 800 |
| Поисковый запрос | ≈ 3 300 | ≈ 9 900 |
| Открытие карточки тайтла | ≈ 10 900 | ≈ 32 700 |
| Запуск воспроизведения | ≈ 6 600 | ≈ 19 800 |
| Добавление/удаление из «Моего списка» | ≈ 900 | ≈ 2 700 |
| Оценка тайтла | ≈ 700 | ≈ 2 100 |
| Синхронизация прогресса просмотра | ≈ 1 050 000 | ≈ 3 150 000 |
